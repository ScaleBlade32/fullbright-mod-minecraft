## 📖 About

Fullbright Mod sets the minimum light level to maximum so you can see in complete darkness without torches, night vision, or any other item.

---

## ✨ Features
<a name="features"></a>

- **Full Brightness** — every block rendered at maximum light.
- **Toggle Key** — switch between fullbright and normal in one key.
- **Gamma Slider** — set any brightness level from 0 to 100.
- **Night Vision Compat** — stacks with potion for extra clarity.
- **No Performance Cost** — pure client-side render change.
- **HUD Indicator** — shows when fullbright is active.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
